This library contains the QSHEXEC Qshell wrapper command and other 
commands that can be used to run Qshell or PASE commands 
and capture STDOUT output to any of the following for 
use from a classic IBM I RPG or CL program:
-Physical file: STDOUTQSH in QTEMP
-Spool file
-Job log
-IFS output log file

It is assumed you have installed the software by creating from
source or copying the library from another system.
